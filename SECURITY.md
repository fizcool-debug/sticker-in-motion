# Security policy

Sticker in Motion is an experimental Android app. Security fixes target the current main branch and the latest published APK.

Please do not post credentials, private camera images or exploitable vulnerability details in a public issue. Use GitHub's **Security → Advisories → Report a vulnerability** private reporting flow when it is available. Otherwise, email the maintainer at **bhaweshkr09@gmail.com** with a minimal reproduction and no secrets; request a secure channel before sharing sensitive material.

For ordinary bugs, use the public issue tracker. Include the app version, device, Android version and WebView version.

Camera images are processed on the device. Any change that adds networking, analytics or image upload must be documented and reviewed explicitly.
